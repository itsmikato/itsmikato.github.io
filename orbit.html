2026 · Firmware for a hardware synthesizer (M-VAVE FM-1) – C, WebAssembly, Python

My own firmware for a small FM synthesizer – and you can play it right here: switch it on, then use the mouse or your computer keyboard. The M-VAVE FM-1 is a pocket synth with a square screen, eight knobs and twenty-seven keys. Its sound is six-operator FM, the kind that is famously hard to program. orbit replaces what runs on it with something I'd want to pick up every day: one button opens one page, and every page is four values over one picture. The four values wear the colours of the four knobs under them – blue, green, white, orange – so you never have to read which knob does what. The same code runs on the instrument on my desk and, compiled to WebAssembly, in this page. What you save here stays in your browser.

Case study

Role

Solo project – interaction design, screen graphics, embedded C, tooling

Tools

Firmware for a hardware synthesizer (M-VAVE FM-1) – C, WebAssembly, Python

The challenge

FM synthesis has dozens of values per sound, and most instruments answer that with menus. I wanted the opposite on a 240-pixel screen: an instrument you can understand by looking at it, with nothing hidden behind a second layer.

Decisions

  1. One button, one page, four values

    The hardware is used as it is printed: each button opens its page, the four knobs are the four values on it, and whatever didn't fit four values and one picture was cut – deep operator editing, a scale page, MIDI settings.

  2. Pictures that are the sound

    The home page draws the six operators as bodies in orbit, wired the way the algorithm wires them; the envelope is its own curve with a dot that moves as you hold a note. Turning a knob changes the picture and the sound together.

  3. Built in the browser first

    The firmware talks to the machine through one small interface, so the same source builds for the chip and for the browser. I designed and tested every page here, with automated tests, and only then installed it on the device.

  4. Your sounds survive

    256 places for sounds instead of 128, a command on the Mac that loads classic DX7 sounds and backs everything up, and program changes from a DAW. An update of the firmware keeps what you saved.

Result

A firmware that runs on my own FM-1 – screen, sound, saving, USB – and in the browser from the same code. It has only run on one unit so far, which is why there is no install button here yet.

What it is built on

The FM sound core and the layer that talks to the chip come from Felucca, an open-source firmware by Leo Kuroshita, and this page's panel is adapted from its emulator; the factory sounds are M-VAVE's. The instrument on top – pages, graphics, voices, effects, sequencer, storage and tools – is mine. orbit is not affiliated with M-VAVE or Teenage Engineering, whose instruments inspired it.
