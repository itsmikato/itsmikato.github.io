A small firmware for the FM-1, here in your browser: the same code the instrument runs. No FM-1 needed. One button, one page; KNOB 1–4 are the four values on it, in their colours.

Pages

HOMEtone · feed · attack · release
EDITratio · fine · level · detune of the picked operator
ENVattack · decay · sustain · release of the picked operator
LFOrate · shape · pitch · level
FXthree values of the picked effect
ARPmode · octaves · rate · gate
SEQpattern · rate · gate · length; recorded by playing
GLOtempo · swing · glide · transpose

SELECT picks the operator, effect or step. ALGORITHM turns through the 32 wirings, PRESETS through the sounds. SAVE held shows where the sound will go; letting go saves. What you save stays in this browser.

Mouse and keyboard

Drag a knob, or scroll over it. Shift-click holds a button down. A MIDI keyboard plays it too.
